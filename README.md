# Ethane-Ethylene Separation Simulation 

**Overview**
This project features a chemical process simulation developed in Aspen Plus to model the separation of an Ethane-Ethylene mixture. The simulation demonstrates practical application of thermodynamics, phase equilibrium, and distillation column design to achieve high-purity product separation.

**Tools Used**
* **Software:** Aspen Plus
* **Key Modules:** [e.g., RadFrac for rigorous distillation]
* **Property Method:** [e.g., Peng-Robinson]

**Key Objectives & Results**
* Successfully simulated the separation of ethane and ethylene to achieve a product purity .
* Optimized column parameters including a reflux ratio at theoretical stages.
* Analyzed temperature and composition profiles to ensure energy efficiency and separation feasibility.

**Repository Contents**
* `Jyotika_Aspen_Assignment.apwz`: The primary Aspen Plus backup file containing the full simulation flowsheet and input parameters. *(Note: Requires Aspen Plus software to open and view).*
